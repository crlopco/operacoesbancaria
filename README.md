Este projeto consiste em uma aplicação desenvolvida para simular as principais operações de um sistema bancário, proporcionando uma experiência simples e intuitiva para o gerenciamento de contas. Com ele, é possível realizar transações essenciais do dia a dia, como depósitos, transferências entre contas e consultas de saldo.

O objetivo do projeto é aplicar conceitos de programação orientada a objetos, manipulação de dados e regras de negócio bancárias, garantindo a integridade das transações e o controle financeiro dos usuários.

🚀 Funcionalidades
Depósito: Adicione valores à conta de forma rápida e segura.
Transferência: Realize transferências entre contas, com validação de saldo disponível.
Consulta de Saldo: Visualize o saldo atualizado da conta em tempo real.
